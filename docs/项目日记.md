## 一、项目简介

云旅ai 是一个「告诉我从哪出发、去哪、玩几天、预算多少、口味偏好，自动生成可执行旅行行程」的网站。

- **后端**：Python + FastAPI
  - `api/` FastAPI 应用与路由（plan / transport / tickets / notes / budget / places / route / share / export / catalog / comments / chat / templates / review / ai）
  - `services/` 业务编排（行程生成、目录检索、预算分档、天气重排、转乘比价、攻略推荐、导出）
  - `core/` 纯算法（行程校验、人群强度、天气重排、预算、偏好学习）
  - `data/` 静态数据（22 城 / 124 景点目录、景点配图元数据、城市经纬度）
  - `datastore/` SQLite、仓储层、数据治理与体检
  - `providers/` 外部数据源与降级链（高德 / 12306 / 门票官网 / 小红书直链 / 本地兜底）
- **前端**：React 18 + TypeScript + Vite，位于 `web/`
- **数据规模**：22 城、124 个真实景点、124 张本地景点配图（离线采集自 Wikimedia Commons，含作者/许可署名）
- **无账号体系**：口味偏好、收藏、搜索历史、AI Key 全部存浏览器 localStorage，不上传服务器存储

## 二、页面地图

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 搜索入口、热门城市、热门景点带图、网友评语 |
| `/search` | 搜索页 | 防抖联想、最近搜索、城市/景点分组结果、结果页签 |
| `/city/:name` | 城市详情 | 城市景点列表、城市画像、网友评语、小红书攻略区块 |
| `/attraction/:name` | 景点详情 | 大图、票价/开放时间/贴士、附近推荐、收藏、纠错入口 |
| `/cities/compare` | 城市对比 | 多城对比表 |
| `/plan/quick` | 快速制定 | 表单化：出发地、目的地、日期、天数、预算档、口味偏好 |
| `/plan/chat` | 自由对话 | 大模型聊天式收集需求，再生成行程 |
| `/plan/:sessionId` | 行程详情 | 逐日行程、预算三档、每日强度、天气重排、转乘比价、拖拽编辑、收藏、导出、分享 |
| `/compare` | 方案对比 | 与已保存模板对比 |
| `/me` | 我的 | 偏好设置、收藏列表、AI 设置入口、审核入口 |
| `/me/ai` | AI 接入设置 | Base URL / API Key / 模型名 / 连接测试（Key 只存 localStorage） |
| `/review` | 纠错审核后台 | 查看与处理用户提交的纠错 |
| `/share/:shortId` | 只读分享页 | 免登录查看他人行程 |

- AI 设置页与「我的」页入口；后端解析用户 Key 并支持连通性测试。
- 制定计划前置 AI 门禁：未接入 AI 时提示先配置或开启本地规则降级。
- 小红书攻略区块：后端给推荐语与搜索直链（只做外链，不搬运内容），前端折叠多段展示。
