# Flutter 课程大作业 —— 云旅 App 提交说明

## 一、压缩包内容

```
├── 云旅App/            # Flutter 完整源码工程（可直接 flutter run / build）
│   ├── lib/            # 源代码（页面 / 服务 / 模型 / 公共组件）
│   ├── assets/data/    # 景点 / 酒店 / 美食 / 城市 / 交通 本地 JSON
│   ├── docs/           # 功能模块清单
│   ├── diagrams/       # 5 张 UML 图（用例 / 活动×2 / 类 / 架构）
│   └── test/           # 单元测试
├── release/windows/    # 已打包的 Windows 可执行程序（yunlv_app.exe）
├── release/web/        # 已打包的网页版（index.html，可用 Edge/Chrome 打开）
└── 提交说明.md
```

## 二、如何运行

- **Windows 已打包版**：进入 `release/windows/`，双击 `yunlv_app.exe` 即可运行
  （需保留同目录下的 `flutter_windows.dll`、`data/`、`sqlite3.dll` 等文件）。
- **Web 网页版**：进入 `release/web/`，用浏览器（Edge/Chrome）打开 `index.html`；
  或本地起一个静态服务器后访问（如 `python -m http.server`）。
- **源码运行**：在 `云旅App/` 目录执行
  ```bash
  flutter pub get
  flutter run
  ```

## 三、如何构建

```bash
flutter build windows   # 生成 Windows exe
flutter build web       # 生成网页版（可用 Edge/Chrome 打开）
flutter build apk       # 生成 Android APK（需先安装 Android Studio / SDK）
```

## 五、AI 配置与安全说明

- AI 增强通过 DeepSeek 实现，Key 配置在 `云旅App/lib/config.dart`。
- 提交源码中 `deepseekApiKey` 已置空，**未包含任何真实密钥**。
- 留空时 App 完全走本地规则引擎，离线可用、演示稳定。

## 六、数据说明

景点 / 酒店 / 美食 / 交通数据均来自「云旅AI」Python 版本地数据迁移
（`云旅App/tools/migrate_data.py`），无实时数据 API，全部离线可用。
