# 云旅 App —— 功能模块清单

> 基于「云旅AI」的 Flutter 移动应用（旅游规划助手）功能与需求梳理。
> 本文档对应课程大作业「软件工程分析与设计」与「课程报告」的素材来源。

---

## 一、项目概述

「云旅 App」是一款帮助用户制定个性化旅游计划的移动应用。用户通过首页选择行程站点 / 途经地，或直接与 AI 对话描述需求（出发地、目的地、天数、人数、预算、游玩时间），App 自动生成多风格行程方案（本地规则引擎 + DeepSeek AI 增强），支持逐日行程查看、增删与拖拽排序、预算实时统计、历史存档、导出行程单。

核心特点：**AI 优先、本地兜底**——联网时调用 DeepSeek 生成智能行程，断网或失败时自动回退本地规则引擎，业务闭环不中断。

## 二、需求清单

### 2.1 功能性需求

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 省份城市浏览 | 按「省份 → 城市」分组展示 20 个热门旅游城市（名称/标签/代表景点），支持搜索 |
| F2 | 需求录入 | 录入出发地、多目的地（省份→城市多选）、日期、人数、人群、口味（多选）、住宿预算、交通偏好、人均预算（自由填写）、跨城班次选择 |
| F3 | 方案生成 | 本地规则引擎生成多种风格方案并附「推荐语」（取消综合评分）；游玩天数按景点时长自动估算 + 途经地优先 |
| F4 | AI 增强 | 调用 DeepSeek 大模型，基于本地真实数据生成智能行程，失败自动降级 |
| F5 | 方案浏览 | 查看方案摘要（推荐语）、每日行程、天气、餐饮、住宿、跨城班次、完整费用明细（门票/三餐/住宿/交通/合计） |
| F6 | 行程编辑 | 增删景点、拖拽调整顺序、实时合计预算 |
| F7 | 历史行程 | 保存历史行程到本地；「我的行程」豆包式布局（左历史列表 + 右 AI 对话） |
| F8 | 行程导出 | 将行程单导出为 .txt / .json 文件 |
| F9 | 个人信息与偏好 | 大概住址、口味偏好（10 项多选）、景点偏好、旅行风格（特种兵·性价比 / 慢游·感受）、三档预算（住宿 / 出行 / 总上限）；首启引导填写 + 一键清理 |
| F10 | 交通查询 | 展示高铁车次、航班方案、景点门票（本地结构化数据）；规划时可选具体高铁 / 航班班次 |
| F11 | 景点推荐与途经地 | 城市 → 景点推荐 → 景点详情，可把想去的景点加入「途经地」，生成方案时优先编排 |
| F12 | AI 对话 | 直接与 AI 助手聊天，询问景点门票 / 开放时间 / 特色等信息（DeepSeek） |
| F13 | 多目的地自动天数 | 长按城市加入行程，游玩天数按各景点游玩时长自动估算，方案按城逐日编排 |
| F14 | 景点图片 | 景点列表 / 详情展示网络示意图片（picsum.photos），断网时回退「渐变 + 主题图标」封面 |
| F15 | AI 对话式行程规划 | 点「开始规划」进入 AI 对话，同步首页已选站点 / 途经地 / 个人信息给 AI，本地解析需求生成方案 |
| F16 | 游玩时间校验 | AI 对话中询问游玩时间：景点超时建议增时 / 减点，空闲推荐补充景点 |

### 2.2 非功能性需求

| 编号 | 维度 | 要求 |
|------|------|------|
| N1 | 性能 | 页面切换流畅，方案生成响应 ≤ 2 秒 |
| N2 | 可用性 | 界面简洁直观，交互反馈明确（加载/错误提示） |
| N3 | 离线可用 | 断网或无 AI Key 时，本地规则引擎保证功能闭环 |
| N4 | 可维护性 | 三层分层、命名规范、关键逻辑注释清晰 |
| N5 | 兼容性 | 支持 Windows（exe）与 Web（Edge 网页）多平台运行，Android 平台工程已就绪（装 SDK 即可打 APK） |

## 三、功能模块划分

### 模块 1：导航框架
- **功能点**：底部导航（首页 / 我的行程 / 我的）、Drawer 抽屉（城市选择 / 历史方案 / 设置）、首页 TabBar
- **对应技术点**：BottomNavigationBar、TabBar、Drawer 三套导航

### 模块 2：省份城市浏览 / 景点推荐 / 需求录入
- **功能点**：按省份分组的城市浏览、城市搜索、景点推荐（含网络示意图片）、景点详情、加入途经地、多目的地需求表单；长按城市加入行程（天数自动估算）、人均预算自由填写、跨城班次选择
- **对应技术点**：Wrap/Flex 布局、SimpleDialog、多选弹层（CheckboxListTile）、表单、Hero 共享动画、ValueNotifier（途经地 / 行程站点状态）、GestureDetector onLongPress、Image.network + errorBuilder 兜底

### 模块 2.1：AI 对话
- **功能点**：与 AI 助手聊天，询问景点门票 / 开放时间 / 特色等信息；上下文注入本地景点数据
- **对应技术点**：HTTP 网络请求、JSON 编解码、Future/async/await、try-catch 异常处理

### 模块 3：行程方案生成（核心）
- **功能点**：
  - 本地规则引擎：5 种风格（经典打卡/文化深度/亲子休闲/美食探店/轻松漫步）、按风格筛选景点、按景点时长自动估算天数、按天编排、生成推荐语
  - DeepSeek AI 增强：把城市真实景点/酒店/美食数据注入 Prompt，生成智能行程文案
  - 降级兜底：AI 请求失败/超时/无 Key → 自动回退本地引擎
- **对应技术点**：HTTP 网络请求、JSON 编解码、Future/async/await、try-catch 异常处理、显式动画（加载旋转）

### 模块 4：方案浏览
- **功能点**：多方案列表（风格/推荐语/景点数）、方案详情、景点/酒店/美食/交通班次分页、完整费用明细
- **对应技术点**：TabBar、卡片布局、隐式动画（AnimatedOpacity/AnimatedContainer）

### 模块 5：行程编辑
- **功能点**：增删景点、拖拽排序、预算实时统计（门票+餐饮+住宿合计）
- **对应技术点**：GestureDetector、Listener、ReorderableListView 拖拽、ValueNotifier 状态管理

### 模块 6：历史行程（我的行程）
- **功能点**：历史行程列表（豆包式：左历史列表 + 右 AI 对话）、删除/清空
- **对应技术点**：SQLite 数据库 CRUD、AlertDialog 确认弹窗、ValueNotifier（切换刷新）

### 模块 7：行程导出
- **功能点**：导出 .txt 文本行程单 / .json 结构化数据
- **对应技术点**：path_provider 文件 IO

### 模块 8：个人信息与偏好设置
- **功能点**：大概住址、口味偏好（10 项多选）、景点偏好、旅行风格（特种兵/慢游）、住宿/出行/总预算上限、首启引导填写、一键清理、关于页
- **对应技术点**：SharedPreferences 键值存储（setString/setBool/setInt/setStringList）、AlertDialog 输入、SimpleDialog 选择

### 模块 9：交通与门票查询
- **功能点**：高铁车次表、航班方案表（舱位价格）、景点门票/开放时间、规划时选择具体班次
- **对应技术点**：本地 JSON 资源加载 + jsonDecode 反序列化

## 五、系统架构（三层）

```
┌─────────────────────────────────────────────┐
│  UI 层  pages / widgets / animations        │
│  (首页/需求录入/方案/行程编辑/我的/设置)        │
├─────────────────────────────────────────────┤
│  业务层  TripPlanner / PlanGenerator         │
│  (规则引擎多风格生成 + DeepSeek 数据注入 + 降级) │
├─────────────────────────────────────────────┤
│  数据层  DataRepository                      │
│  JSON资源 + SQLite + SharedPreferences + 文件IO │
└─────────────────────────────────────────────┘
```

**数据链路**：本地城市 JSON 资源 + DeepSeek(网络) → 内存(方案/行程) → SQLite 持久化(历史) → 文件导出(行程单)。
